CHALLENGE & INNOVATION

Problem Statement & Solution Provided

Modernizing urban grievance management with AI automation and hyper-local GIS

⚠️ THE PROBLEM STATEMENT
• Slow & Fragmented Redressal Citizens face bureaucratic delays with opaque grievance systems offering zero visibility on report status.
• Spam & Staff Overload Municipal teams waste hundreds of hours manually screening irrelevant, duplicate, or fake photos.
• Vague Locations General city names (e.g. "Coimbatore") lack specific locality context, causing field squads to search aimlessly.
• Citizen Privacy Violations Unregulated public photos capture pedestrians' faces, posing compliance and legal risks.
✔ THE CIVICFIX SOLUTION
• AI Vision Verification (Gemini 1.5) Automated analysis verifies genuine road damage, potholes, and garbage while auto-suggesting descriptions.
• Automated Privacy Shield Detects human faces in photos and instantly rejects submissions to protect citizen privacy.
• Hyper-Local GIS Tagging Pinpoints exact localities (Eachanari, Gandhipuram, etc.) with OpenStreetMap embeds and Google turn-by-turn navigation.
• Role-Based Authority Hub Department-segregated review queue (Roads, Sanitation, Water) with live status tracking for citizens.
CLOUD INFRASTRUCTURE

AWS Cloud Architecture

Enterprise-grade deployment on Amazon Web Services ensuring reliability and speed

☁️ Amazon EC2
Compute & Hosting Hosts Dockerized multi-tier stack (Nginx, Spring Boot backend, MySQL container).
Ubuntu 24.04 LTS Configured with auto-restart daemon policies for continuous availability.
🗄️ Amazon S3
Cloud Object Storage Scalable, durable bucket for high-res civic issue photos with public CDN URLs.
Local Volume Fallback Seamless fallback to local container storage if S3 connectivity is unavailable.
🔒 AWS VPC & Sec
Network Isolation Strict Security Group firewalls exposing only Port 80 HTTP for the web proxy.
Internal Bridge Internal container network prevents unauthorized access to MySQL Port 3306.
🔑 AWS IAM
Least Privilege Role-based credential-less access between EC2 and Amazon S3 buckets.
Environment Vault Encrypted environment variables for Gemini AI and database credentials.
